# The Pizzeria Roleplay Remastered Public Assets

This repository hosts game assets for our game, '[The Pizzeria Roleplay: Remastered](https://www.roblox.com/games/373513488/FNAF-RP-TPRR)' which we are comfortable with releasing to the public!

We invite TPRR players and the wider community to use these assets to learn, to help with their own projects, & more! So long as the creators are credited and usage abides by the included [creative commons license](./LICENSE). Regarding this,

- We make no claims to the designs or characters we are inspired from, only our own derivative works.
- If you'd like to request an asset be made public, the best way to do so would be to make an issue. We'll do our best to keep up!
